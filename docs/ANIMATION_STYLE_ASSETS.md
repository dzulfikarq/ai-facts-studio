# Animation Style Gallery assets

Gallery uses only local, six-second excerpts from source animation. No AI-generated previews, SVG/CSS illustration, procedural art, or hotlinked media. Each bundled clip is muted and transcoded to H.264 MP4; its JPEG poster is an actual frame from that excerpt. Card posters use a consistent 16:9 crop.
